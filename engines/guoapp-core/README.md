重建原生核心：将 `参考/tools/mingw64/bin` 加入当前进程 PATH，在 `参考/guoapp` 执行 `python scripts/build_native.py --platform windows`，再复制 `windows/runner/duanju_core.dll` 并更新清单校验值。原始 Flutter 工程保留在参考目录；接入现有软件只需要此原生组件。

目录、搜索和分集字段来自原生核心；下载只使用所选剧集及其对应分集，来源未返回有效播放数据时保留失败结果。媒体会先经核心下载，再核验并转存到选定素材目录，最终使用现有素材入库与制作队列。
