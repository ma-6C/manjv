# 漫剧工坊 0.9.3：下载接口与独立剧集目录

日期：2026-10-29。

本版从当前源码重新编译主程序，包含红果下载组件更新与按单部剧保存的规则。独立客户核对工具不属于本次安装包，也不要求客户运行额外工具或生成报告。

## 修改内容

- 原生下载组件使用 `0.2.68+75-manju.2`，包含新的播放接口、匿名设备注册与进程内身份复用、播放响应解析。保留画质选择、分段下载和断点续传。设备令牌、Cookie 和客户运行数据不打入安装包。
- 每部剧写入 `红果原生/剧名__剧集ID/`；旧目录映射指向母目录或不符合本剧目录规则时，改用规范的独立目录并记录提示。
- 继续下载时核对已有目录内资料的来源和剧集 ID，遇到其他剧或损坏资料停止写入；不按缩略图、现有集号猜测旧视频归属，不自动移动或覆盖已经混放的视频。
- 沿用 0.9.2 的 STTN 独立设备选择、首个 CUDA 错误诊断和新进程 CPU 回退；离线 AI 引擎继续使用已有 v2-cu128 包，不重新制作或改写其模型与运行库。

## 升级与交付

交付目录为 `release/v0.9.3/对外发送/`。退出旧版后运行 `漫剧工坊-安装程序-0.9.3.exe`，覆盖安装到原目录。已导入 v2-cu128 的客户只需要更新主程序；需要该引擎的新客户可同时接收沿用的 `漫剧工坊-AI离线引擎-v2-cu128.zip`，通过安装程序的可选导入或软件的“授权与组件”导入。

客户项目、下载记录、设备授权及模型保留原保存位置。下载失败任务可从原任务入口继续剩余集；应用升级本身不会重新下载已完成的视频。

## 构建与验证边界

本版重新记录构建输入、编译产品模块、核对打包的原生 DLL 与清单、签署应用完整性清单，再构建安装程序。构建记录与文件 SHA256 保存在 `versions/v0.9.3/` 和交付目录。

按用户要求，本轮不运行下载、模型、浏览器、安装或客户硬件测试。已有原生组件专项记录属于先前验证，不作为本次安装包运行验收；本版交付状态为已编译、签名和封装，未运行安装验收。
