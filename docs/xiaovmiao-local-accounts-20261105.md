## 修复内容

1. 原来的全局 `net.request` 禁用也会阻断 Electron 会话请求。这次只允许 `https://creator.douyin.com/web/api/media/user/info/`，其余后台请求仍保留原限制。
2. 在当前抖音网页会话里通过 Electron Cookie API 取得此官方地址适用的 Cookie，只在内存中构建资料请求。请求固定为抖音官方当前用户资料接口，禁止重定向，不读取浏览器 Cookie 文件、不记录 Cookie 值。
3. 只接受官方当前用户接口返回的有效 UID 和昵称。识别失败或未登录时，不创建账号。界面新增实时状态，区分等待登录、读取资料、保存成功、资料格式未识别与请求失败。
4. 将资料保存到实际 SQLite `Account` 表，默认分组为 0，UID 与平台查重，重复登记保持一条。登记前自动在数据库旁的 `manju-backups` 创建 SQLite 一致性备份。
5. 从真实数据库恢复本地列表及对应的原生账号对象，保留原会话分区，使点击账号继续使用该分区。登录失效时保留账号记录。
6. 账号列表为空且尚未进行本次迁移时，启动后检查该应用自身的持久会话分区，仅查询其中的抖音登录态。有效会话可自动恢复到默认分组，不需要先重新扫码。只扫描当前应用自己的 `electron/Partitions`，不扫描其他浏览器。一次迁移的状态记录在数据库旁的 `manju-session-recovery-v1.json`。
7. 允许主界面加载抖音头像 CDN 的图片；不因此放开任意后台网址。仅为基本账号列表接入本地代理/分组辅助数据，不恢复软件云端账号系统。
