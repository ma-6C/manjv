# 漫剧工坊 0.9.0 交付说明

日期：2026-10-27。代码分支为 `codex/unified-production-window`；保留 `main` 和旧版本标签。

## 发送文件

客户安装程序：`release/v0.9.0/对外发送/漫剧工坊-安装程序-0.9.0.exe`。

同目录包含客户安装说明、验收摘要及 SHA256。旧客户退出软件后覆盖安装到原目录；已有有效设备授权、素材和已导入的 v1 离线 AI 引擎继续使用。主包不含模型；需要新装本地 AI 的客户使用原来的独立 v1 引擎包。

## 本版内容

- 开始制作后在一个独立窗口内推进真实任务，显示当前步骤、实际进度、待补项和下一操作。暂停、恢复、收起到后台保留已完成结果。
- 完整视频和连续多集字幕处理保留框选区域范围，可选择 STTN 时序修复或 LaMa 框选修复，连续多集复用模型。
- 生成可编辑剪映草稿并导入本机草稿目录；工程证明使用实际剪映窗口采集。移除自绘工程图与即梦入口，历史来源不再作为当前有效工程证明。
- 发布资料有缺项或中途变更时，在同一个窗口补充；本人保存并核对后继续，普通轮询不重复创建任务、填表或上传。
- 安装前检查实际 VC++ DLL 与 WebView2，已就绪时跳过重复安装；确实缺少时使用可取消、最长等待十分钟的安装监督流程并保留日志。

## 本次修复

1. 导出没有实际任务引用时不能显示完成。资料版本变化会停在明确核对状态，确认新资料后按新版本创建或恢复导出任务；多部剧定位实际缺项剧目。
2. 官方发布网页首次打开失败后，显式恢复可以重新打开。普通轮询不会重复打开浏览器；辅助填写中断仍要求本人核对已有内容。
3. 导出和发布准备的资料恢复均直接显示在制作窗口内，保留输入框、光标与未保存内容；历史步骤保持只读。

## 已知边界

- 剪映部分版本不能自动定位指定草稿，尤其本机11.6的首页UIA存在限制。此时明确等待用户打开列出的工程，再重新检测；复制草稿不等于工程已在编辑器中打开。
- `jy-draftc` 原生渲染仍为开发探针，未进入本版正式功能，也没有将剪映官方程序、DLL或Yichen源码打入安装包。
- 发布最终提交和平台审核仍由本人及官方后台完成。本次没有实际提交平台或验证整套审核通过。
- 下载采用本机受控HTTP验证；没有重新计时外网整剧，也未在所有显卡型号或全新Windows虚拟机逐一实测。应用完整性签名保持启用，未配置Windows Authenticode发布者证书。
