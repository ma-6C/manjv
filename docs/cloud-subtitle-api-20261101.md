# 云端 AI 去字幕接口与模型选择

实现日期：2026-11-01。改动已进入当前源码，尚未生成新的客户安装包。

## 使用方式

1. 打开「AI 去字幕 → 设置 → 云端服务连接」。
2. 填写字幕服务的 HTTPS 网址及 API 密钥，停止输入约 0.7 秒后自动获取模型。也可点击「刷新模型」。
3. 搜索并选择字幕模型，或手动填写模型 ID。原有不需要模型参数的字幕适配器可以留空。
4. 在「高级设置 · 字幕任务协议」中，按服务商文档核对提交、查询路径。
5. 点击固定底栏或表单内的「保存去字幕接口」。密钥保留在本次运行中，不写入配置或任务文件。
6. 到「完整制作设置」选择「云端 AI 适配器」。先执行 5 秒短片试处理，确认效果后再处理整集。

保存接口不会自动改变本地或云端处理方式。已有本地引擎、选区、文案和封面配置保持原样。

## 模型查询与视频处理

云端字幕仍使用现有的 `subtitle_json` 适配器协议、Bearer 鉴权和 JSON 视频任务格式。此次增加模型查询、选择和实际参数传递，没有将任意文字或生图接口转换成去字幕接口。

只填根网址时，模型查询优先尝试同一服务的 `/v1/models`，必要时尝试根路径的 `/models`。字幕提交网址保持用户填写的服务基址；模型列表的版本前缀不会自动加到视频提交路径上。

字幕提交格式为：

```json
{
  "filename": "视频.mp4",
  "video_base64": "视频内容的 Base64",
  "region": {"x": 0.05, "y": 0.78, "w": 0.9, "h": 0.14},
  "model": "用户选中的模型 ID"
}
```

模型留空时不提交 `model` 字段。同步响应返回 `video_url`；异步响应返回 `task_id`，再向配置的查询路径提交该编号。返回的视频经下载和媒体检查后才登记为结果。每个任务沿用创建时的连接与模型快照；后续修改只作用于新任务。

现有单文件 80 MB 和单字幕选区限制继续适用。具体服务若采用其他上传字段、签名或任务格式，仍需提供其去字幕 API 文档进行专项适配。

## 已有配置

- 既有命名字幕连接可选择、编辑并继续使用，主备设置仍然有效。
- 选择「新建字幕接口」后，可从旧版完整提交和查询地址生成同域路径草稿；显式保存后建立独立命名连接。
- 旧版 `subtitleEndpoint`、`subtitlePoll` 和会话密钥入口仍留在后端兼容逻辑中，未改写历史任务。
- 新输入的密钥只用于草稿查询；保存接口时才设置该连接的会话密钥，避免迟到查询覆盖后来保存的凭据。
- 关闭字幕设置会取消待处理的页面模型查询并清空输入框中的密钥。
