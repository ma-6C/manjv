## 已修复问题

- 损坏或不可读的 `state.json`、`jobs.json` 不再静默生成空工作区。启动和保存均显式停止并保留原件，提供上一份有效备份位置。
- 保存前校验新内容；每个文件原子保留上一份有效 `.json.bak`。备份失败停止写入；不自动回滚云端任务，不声称跨文件事务或物理断电保证。
- 关闭期间拒绝新建/恢复任务；关闭后才结束的 worker 保持中断状态。新建/恢复/出队持久化失败会回滚或停止处理，避免隐藏队列和重复执行。
- 桌面启动时读取数据失败会显示错误并写启动日志；日志目录不可写时也会给出提示。桌面默认最大化，保证小屏下底部制作操作可见。
- 环境检测独立于工作台加载和状态更新；检测失败仍可编辑与查看任务。初次连接失败自动重试并提供立即重试按钮，连接恢复后文字状态同步恢复。
- 请求超时、网络故障和非 JSON 服务错误显示可操作的信息。写入操作不设置默认超时，避免客户端自行中止后误导用户重复提交。
- 后台制作完成不再覆盖正在编辑或未保存的剧名、简介。
- 构建拒绝覆盖已有非空版本目录、已有安装包和已有构建输入记录。小v喵按清单核对文件集合和哈希后复制，拒绝意外加入用户 profile、Cookie 或额外文件。

- 原生混剪或云端成片损坏后恢复，会按原 clip ID 刷新文件大小、哈希和修改时间，保留创建时间，不重复登记或重新提交云任务。
- 逐段编码与合成后重新检查源素材/字幕快照；处理期间素材被替换即停止，不登记基于旧分析的错误成片。
- 片尾引导文案按实际字体宽度自动换行并放在底部安全区域，长文案不再被左右裁切。

新增片尾原画保留设置，支持本地 LaMa 框选和 STTN 时序修复。默认 0 秒，按每个源视频的实际帧数计算保护范围。短片试处理按原片时间映射，修改设置后提示已有试处理过期。
