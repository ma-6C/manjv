# 移除 AI 视频生成 · 2026-10-24

用户取消文生视频、图生视频模块。本次为源码开发变更，未生成安装包。

- 移除视频生成导航、页面、表单、任务栏生成按钮、模型协议和接口用途选项。
- 旧 `#generate` 书签返回源内容扫描；AI 接口仅保留文字、封面生图、云端字幕。
- 移除生成任务提交/查询实现及绑定云端任务 ID 的接口。保存配置加载时清理旧视频生成连接和路由；保留其他用途的连接。
- 历史生成任务及结果文件保留。尚未结束的本机生成/查询任务标记为停用，不自动继续，也不能恢复；已提交到外部平台的任务需到原平台核对。
- 原 `video_api.py` 删除。云端字幕仍需使用的有界 HTTPS 下载函数独立为 `media_download.py`，构建脚本相应调整。
- 封面生图、剧名简介、多接口主备、已有素材的下载/剪辑/去字幕继续保留。

验证覆盖接口配置迁移、旧任务停用、生成请求拒绝、已有文件保留、文字与封面生成、云端字幕结果入库、会话密钥不落盘，以及真实浏览器中的导航、接口表单和旧路由跳转。云端响应使用隔离模拟，不代表本轮进行了付费服务调用。
