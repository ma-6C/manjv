# 真实草稿、高光布局及模型复用

本次为源码功能更新，没有生成安装包，也没有改动 0.8.6 基线。

## 高光去重

高光页按用户提供的功能排列调整，沿用本软件现有的浅色紫色界面：

1. 顶部左侧输入：添加文件、导入文件夹、清空、移除、加入当前剧集、自由选集、加入当前成片。
2. 顶部右侧输出：输出根目录、预计生成份数与总时长、任务提交结果、开始生成。
3. 生成设置：份数、固定倍率、并行数、随机倍率区间、定格段配乐、低占用模式、GPU 加速。
4. 结尾模板：启用开关、模板目录、指定或随机模板、定格文字。

时长公式为 `(原片时长 / 播放速度 + 所选片尾时长) × (1 + 定格倍率)`。估算区域尚未选择实际片尾时不包含片尾时长，并明确标注。固定倍率和随机区间独立保存；旧设置在首次读取时将原最小倍率迁移为固定倍率。

一次滤镜编码完成源片、可选片尾拼接、最后一帧定格、音频拼接、定格配乐循环与文字。片尾拼接后重新确定帧率再定格，防止只有音轨延长、后段缺少视频帧。成品检查文件时长、音轨和末段画面后才登记。原片不修改。

并行数为 1–8；低占用模式使用 CPU 单路，保留原 GPU 选项。常规模式沿用硬件实测及 CPU 自动回退，不承诺所有显卡均通过硬件编码。任务提前固定每份随机倍率、模板及素材状态，暂停恢复不重新抽取。选定原片时不被旧成片替换；完整制作流程继续使用本次成片。

## 剪映真实工程

「分轨工程图」页上方新增独立的「剪映真实工程」区域，下方旧 PNG 功能继续保留。

- 支持共用所选原视频的顺序，或导出所选剧集当前成片、去字幕结果；每批 1–30 个。
- 使用 `pyJianYingDraft 0.3.1` 创建真实草稿，不画仿剪映截图。
- 真实镜头分段建立画面剪辑轨；原声独立提取为 AAC 音轨并关闭视频轨重复声音。
- 同名 SRT 存在时导入字幕轨；SRT 超过视频时长则提示失败，避免生成时长错误的草稿。
- 每个工程有独立的新目录，包含 `draft_content.json`、`draft_meta_info.json`、`Resources/` 和 `manju_project.json`。
- 素材复制并核对 SHA256；只有校验完成才移除未完成标记并登记结果。已完成工程可恢复复用。
- 移动完整工程目录后，可使用页面「重新定位素材」，仅改本工具自包含工程里的资源路径，重新校验，不改原素材。

**本机尚未安装剪映主程序。** 已验证草稿可被公开组件重新读取、实际轨道与片段时间线、资源完整性、移动后重连。没有验证某版剪映主程序能打开、播放、编辑或导出。安装剪映后，将工程放入该版本本地草稿目录并核验；目前不自动改动剪映的全局项目索引，也不提供虚假的编辑器截图或审核通过承诺。

## STTN-auto 批量复用

本地 AI 设置新增「批量复用 AI 模型」。STTN-auto 连续处理时共用 Python 进程和修复模型，空闲 120 秒退出，暂停、停止或应用退出会释放进程。运行环境或模型文件状态变化后重启；出错清理后允许重试。其他模式以及关闭开关时仍用原有逐集进程路径。

实现为本软件持有的子进程适配器，不修改已安装的离线引擎文件。JSON 行协议与日志分离，任务 ID 核对响应，仍保留每集完整时长、音轨和输出校验。

两段相同的 2 秒、640×368、6fps 样片实测：首次启动约 63.58 秒，第二段复用后约 1.67 秒；同一 PID，模型加载一次，第二次命中复用。该数据体现冷启动成本，不是整剧、1080p 或 30fps 的速度承诺。

## 验证

- `verify_production_components.py`：21 项真实媒体检查，包括真实草稿读回、轨道/字幕、资源校验、移动重连、取消、顺序、原片哈希、片尾/定格/配乐、并行及低占用模式。
- `verify_production_components_ui.cjs`：24 项真实 Edge 界面及任务结果检查。
- `verify_vsr_pool.py`：10 项实际 AI 与受控工作进程生命周期检查。
- `verify_subtitle_full.py`：13 项完整时长、选区范围、连续处理、失败恢复和音轨回补回归。
- `verify_production_handoff.py`、`verify_gpu_fallback.py`：原连续制作、接续制作、硬件编码与回退检查。

测试全部使用独立 `MANJU_DATA` 和本地样片，不代表客户整部剧、剪映主程序、外部平台审核或安装包已验收。
