# 漫剧工坊 0.10.1

发布日期：2026-11-01。

文案、封面和云端去字幕接口支持填写 HTTPS 网址及密钥后自动获取模型，并提供搜索、下拉选择、手动填写与刷新。兼容服务根网址自动识别模型查询前缀，鉴权错误、空列表及接口格式错误在当前设置内显示。接口参数保存到本机，密钥仅留在当前运行会话。

云端去字幕设置保留独立提交、查询路径，所选模型实际随视频任务提交；模型查询前缀不改变视频上传地址。固定底栏提供保存按钮。既有本地修复引擎、命名连接及主备设置继续兼容。

已从源码版实际界面使用客户服务验证自动获取 5 个模型和一次 Gemini 原生生图：自定义服务、`https://ai.yuliapi.com/v1beta`、Gemini 生图、`gemini-nano-banana-2.1`。AI 原图和 816×1086 封面均已保存。该服务的 Images Generations 请求返回过转换失败，默认字幕路径未通过真实试处理；本版不把成功获取模型列表视为去字幕成功。

客户应填写自己的密钥。发行包不含测试密钥、账号、授权签发材料、本机项目、生成图或测试视频。

主程序安装包继续使用原有签名完整性清单和设备授权校验。已安装 v2-cu128 本地去字幕引擎的用户只需更新主程序，无需重复导入引擎。本次不修改或重新生成离线 AI 引擎。
