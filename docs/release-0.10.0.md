# 漫剧工坊 0.10.0

日期：2026-10-31。

本版将文案与封面的接口配置收进该页面右上角的“设置”，删除侧栏“任务与系统”的 AI 接口入口和底部“选择接口”。旧的 `#api` 页面书签转到文案与封面。

设置左侧分别为“文案接口”和“封面接口”，各自保存平台、协议、地址、模型和会话密钥；可继续使用已有连接及已保存的主备选择。参数沿用原配置字段和凭据隔离方式，历史连接、任务和接口调用记录保留。后台刷新、切换分类、保存或测试不重建主页面，保留未保存的剧名和简介。错误直接显示在当前接口设置内，保存失败后可重试。密钥只保存于当前服务进程，不写入配置或发行包。

本版也包含此前已提交的剪映工程、实际素材登记、AI 诊断与 2–10 秒随机切片改进。用户选择的来源视频、已有草稿、下载记录和授权不随打包迁移或删除。

## 配套引擎范围

交付合集中包含既有签名的 `漫剧工坊-AI离线引擎-v2-cu128.zip`，用于 STTN 等本地去字幕修复。主程序完整性清单与引擎组件签名分别校验。

这个既有去字幕组件不包含剪映工程新增的 Demucs 人声分离、faster-whisper 识别依赖和模型。主程序中的这些功能需要另外配置包含对应依赖及本地模型的 Python 引擎；本机开发环境不能直接作为客户可移植引擎发送。此次集合打包不会改变既有 v2 包的运行库或适用性，也不宣称已在客户 RTX 5060 硬件验收。

## 验证与交付

接口设置通过隔离源码服务的 25 项界面检查及原有 26 项接口/凭据测试；文字调用和生图模型列表的测试响应为受控样例，没有消费客户接口。检查覆盖两类接口独立保存、原连接兼容、未保存文案保留、后台刷新、错误重试、重新载入、键盘操作及窄窗口布局。

本次重新编译、签署应用完整性清单并构建安装程序，随后将安装程序和原 v2 离线引擎封装进同一个 ZIP64 合集。构建记录和散列位于 `versions/v0.10.0/` 与交付目录。未运行安装覆盖、真实模型或客户显卡验收。
