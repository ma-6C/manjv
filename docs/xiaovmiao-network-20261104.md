# 小v喵抖音登录页空白修复

> 最新状态：已交付保持直接进入主界面的本地账号适配版，见 `docs/xiaovmiao-local-accounts-20261105.md`。以下内容为此前阶段记录。

## 根因与修改

用户截图中的小v喵主窗口已经启动，空白的是其内部抖音登录网页。检查用户指定的修复版发现 `main.js` 中同时存在 `MAP * ~NOTFOUND` 全局域名限制，以及取消所有 HTTP/HTTPS/WebSocket 请求的会话拦截。其运行记录也包含 `Offline local mode: external operation unavailable`。

在工作目录的 `modules/xiaovmiao/程序` 副本中取消全局域名限制，为平台 `<webview>` 会话恢复正常的网页联网。主应用会话和已有后端云调用仍沿用原有限制。本次只修改归档中的 `main.js`，并加入 `manju_platform_network.js`；编译后端、preload、登录逻辑以及其他归档文件的 SHA-256 均与用户指定源程序相同。

工具：`tools/repair_xiaovmiao_network.py`。原程序未修改，旧程序归档和 EXE 的备份另存于 `tmp/xiaovmiao-network-backup`。新的 Electron 归档完整性元数据随修复归档更新，未关闭其完整性校验。

## 入口和原数据

本机 `data/xiaovmiao.json` 的程序入口已切换到工作目录的修复副本。原来的

`D:\小v喵\本地初始化修复_20261103\本地数据`

作为显式配置传给修复副本，继续使用这份数据库、配置、缓存和会话。没有复制、清理或重建用户数据。目录如果移动，启动将报告错误，不会静默切换到新空库。

旧进程必须退出后，重启源码版漫剧工坊再点击“小v喵”。也可运行工作目录的 `启动小v喵.ps1`，它读取与模块相同的配置。直接双击副本 EXE 不会读取漫剧工坊的路径配置，不能代替这个入口。
