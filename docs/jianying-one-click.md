# 工程图默认自动配置

本轮根据用户提供的转码页/出图导航和函数索引调整操作入口。目标是在工程图页面选集后点击一个主按钮，由后台统一执行，不要求用户依次操作生成草稿、导入、打开和截图。

- 页面默认使用固定自动方案，覆盖旧任务残留的手动开关；本机输出、剪映和引擎位置仍可沿用已有有效配置。
- 剪映位置和草稿库沿用已有自动检测；AI Python 与模型按本机引擎的标准位置查找；声音素材按本机可用素材库选择。
- 补充参考软件截图及 `jy_materials` 常量后的素材规则：自动探测剪映的 `User Data/Cache/music` 或 `User Data/Cloud files`；按实际时长分类，BGM ≥100秒，音效为1.5～15秒，最新下载优先并尽量轮换。素材在后台识别、按本集固定选择并记录文件快照，HTTP 创建任务时不逐个解析整个缓存。已有 `bgm/sfx` 分类目录仍兼容。
- BGM 默认关闭，保留原片声音；主动启用自定义配乐时才添加 BGM。缓存没有合适音效时明确记录，不假设缓存里一定已有素材，也不自动下载或伪造素材。
- 常规页面只显示素材选择、出图结果与成功/未完成数量。原参数放入“本页设置”；只有主动启用自定义方案才使用自定义剪辑参数。
- `jianying_jobs.run` 逐集串联生成、导入和真实窗口截图。草稿、导入副本和图片记录分别落盘；恢复时核对已保存文件并跳过有效图片，不把草稿已生成算作图片已生成。
- 多集切换时，仅向本批已出图的已登记工程请求正常退出；保存提示、其他工程、窗口无法确认等情况会停止自动操作并保留进度，不强制杀死剪映。
- 生成失败可以记录到对应集并继续不依赖桌面的处理；遇到剪映窗口或保存提示则停止批次，避免对错误工程继续发送动作。页面提供“继续未完成部分”。
- 自动方案要求真实分离音轨和有效字幕。缺模型或 AI 未完成时停止并保留未完成文件供排错，本集不记为完成；不会用混合原声冒充分离结果。

根据用户补充的“定位并打开第一个草稿”，打开策略调整为：空闲剪映首页先正常退出；登记并置顶本次导入副本，同时更新可读草稿元数据中的封面和修改时间；重新启动剪映后，以本次封面标记定位置顶草稿并双击。当前首页不提供草稿标题控件时不再要求先找到标题，也不再向下滚动寻找其他卡片。点击前核对首条可见索引的名称、目录和草稿 ID，打开后仍须核对真实工程标题及时间线。遇到其他编辑工程或退出提示时保留进度。

Qt版不提供完整标题控件时，从实际窗口标题条读取本次15位数字工程编号（兼容旧版12位十六进制编号），必须精确匹配。小字号使用多个对比度视图重试识别；不模糊匹配。记录 `projectIdentityVerified`，不把编号确认谎报为完整标题确认。窗口改变、编号无法识别时停止动作并保存原因。

“本页设置 → GPU运行库”支持自动、PyTorch自带库、NVIDIA独立包。每次尝试均启动新进程；自动按Torch GPU、NVIDIA GPU、CPU顺序尝试，仅在明确的GPU错误时回退。新任务采用保存后的选择。

任务日志按步骤记录输入视频、尝试序号、设备、实际库路径/版本、耗时和输出数量；失败立即记录原始错误与技术栈、下一步及自动回退方向。每个AI步骤另存 `Resources/AI任务/*-attempts.json`，完整记录不会被后续CPU重试覆盖。“导出诊断”包含各次结果和版本，按现有规则隐藏密钥及完整本地路径。进度持续更新，但不为同一阶段反复写相同日志。

代码与配置说明进入源码仓库；本机模型、AI运行环境、视频和原始运行日志不入库。源码更新与安装包发行分开进行。

## 2～10秒随机切片（2026-10-30）

新建自动工程默认采用2～10秒的随机素材时长，原场景边界改为候选切点；过短场景会合并，长片段会拆分。先确定可覆盖全片的片段数量，再为后续片段预留至少2秒，避免最后留下不足2秒的尾片。原片不足2秒时保留原长。

切片种子按任务和源视频固定，并与完整切点记录一起保存到工程清单及任务日志。新建任务可以得到不同切点；同一任务重试不会改变切点。已生成的旧工程保持不动。
