# 任务失败日志改进

日期：2026-10-27；基于 `d8cc74e8` 的开发源码，未重新打包。

## 行为

- 任务失败保留实际处理阶段、剧目、视频名、程序名、退出码、错误类型和发生时间，不再统一覆盖成“任务失败”。并行 FFmpeg 错误记录失败进程对应的视频，不取另一条活动进度的名字。
- 日志页、制作进度页和独立制作窗口共用失败说明：中文原因概述、原始报错、下一步操作，技术详情按需展开。没有足够证据时保留原报错，不编造原因。
- 日志默认展示错误与提醒；失败任务优先排列。可以只看一个任务，也能按视频、步骤、剧目或报错搜索；需要执行记录时切换全部级别。右侧“最近动态”改为“错误与提醒”，已完成或已停止任务的旧问题不再占据该列表。
- 保留 stderr 的关键错误和末尾输出；stderr 为空时使用 stdout。记录超时的外部程序及退出情况，避免只显示“媒体命令超时”。
- 轮询保留展开的技术详情与正在选择复制的文字。日志不变化时保留已有 DOM。
- 文本日志导出包含关联上下文、原始错误、退出码和调用堆栈；支持按任务导出。任务诊断 JSON 摘要增加失败原因、阶段、文件名和建议，排除完整路径和堆栈。
- 新日志隐藏当前会话密钥以及常见 Bearer、查询参数和密钥字段；重试启动时清除旧错误，成功后不会继续显示上次失败。
- 历史失败任务可以从原错误与已保存阶段生成说明；历史未记录的退出码、堆栈等信息不能补造。
