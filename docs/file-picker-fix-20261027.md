# 文件／文件夹浏览窗口 WinError 2 修复

日期：2026-10-27。用户确认第二张客户照片中的 WinError 2 出现在点击“浏览”、选择文件夹或引擎 Python 时，选择窗口没有打开。该现象与 STTN 处理后的输出校验失败分别处理。

## 原因与修改

原 `/api/browse` 的各选择器都通过短命令 `powershell` 启动。客户环境无法解析该命令时，CreateProcess 直接返回 WinError 2；此时还没有选择或运行引擎 Python。

- 桌面版使用所属应用窗口的原生对话框，在 Windows STA UI 线程上调用。通过窗体拥有关系显示，不启动 PowerShell 进程。
- 浏览器模式优先使用 Windows 系统目录中的 PowerShell 完整路径，PATH 中的命令仅作为后备。
- Python 仍使用 exe 文件筛选；VSR 目录使用文件夹筛选；视频、附件多选等返回契约保持一致。
- 区分取消、已有窗口、等待超时、启动文件不存在和底层选择器报错。失败时记录具体原因，保留手工粘贴路径的入口。
- 新模块已加入正式编译模块清单；尚未构建新安装包。

## 验证

`verify_file_picker.py` 共 23 项通过。实际清空测试进程 PATH 后，旧命令复现 WinError 2；改用系统完整路径后 PowerShell 可正常启动。其余检查包括中文路径、取消、多选、重复窗口、各筛选模式与底层失败。

独立桌面验证窗口使用相同的原生调用，并在调用期间清空该测试进程 PATH。已实际观察到 Windows 文件夹选择窗口正常弹出；本机交互记录还包含文件夹和 Python 文件窗口取消后返回空路径。代码层验证了中文路径返回。验证没有改变系统 PATH 或客户配置。

本轮交付为开发源码；客户现有安装程序需要更新后才能使用修复。
