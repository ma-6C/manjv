# 文案与封面接口：自动获取模型

实现日期：2026-11-01。适用范围：当前源码；未重新生成客户安装包。

## 客户操作

1. 打开「文案与封面 → 设置」，选择文案接口或封面接口。
2. 填写 HTTPS 接口网址和 API 密钥。停止输入约 0.7 秒后自动查询模型，无需预先填写模型 ID 或保存配置。
3. 在「搜索模型」中输入关键词，从下拉列表选择模型。
4. 点击对应的保存按钮。文案可使用「测试文字调用」发起一次简短请求；封面检测只查询模型列表，实际生图仍由封面生成任务验证。

仅填写兼容服务的根网址时，会先尝试同一服务的 `/v1/models`；方舟、百炼、OpenRouter、Gemini 等内置平台使用各自预设的 API 前缀。用户已填写的网关路径保持原样，不重复追加版本前缀。只有路径不存在或返回内容不是模型列表时，才尝试根路径；鉴权失败、权限不足、限流、网络异常不切换路径重试。

已识别的平台使用其默认协议，其他服务默认使用兼容协议。特殊服务可以在「高级设置 · 平台与协议」中调整。模型列表接口无法自动证明某个模型应当使用哪一种生成协议。

## 查询和保存

- 查询只读取草稿，不保存连接、模型选择或任务路由；新输入的密钥也不会在查询成功时替换已保存的会话密钥。
- 已保存的会话密钥可用于刷新同一个接口；自动规范地址时，保留对应会话凭据。密钥不写入配置文件。
- 模型列表支持搜索和手动填写 ID，不再截断至前 500 个模型。Gemini、Anthropic 原生列表支持分页读取，分页异常会明确失败。
- 平台没有模型查询接口或返回空列表时，会给出提示，并保留手动填写、保存模型 ID 的能力。
- 输入变化后取消旧查询；迟到响应不能覆盖新网址、新密钥对应的列表或其他连接的表单。关闭设置、切换连接会取消待处理的页面查询。
- 文案和封面独立设置；查询模型不会触发生成。

列表展示的是平台向当前密钥返回的模型。实际可调用性还取决于模型权限、余额、协议和用途，不将获取列表表述为生成成功。
