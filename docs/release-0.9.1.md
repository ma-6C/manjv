# 漫剧工坊 0.9.1

日期：2026-10-27。基于主分支制作，保留 0.9.0 旧安装包及原有版本记录。

## 本版修复

- 文件夹、引擎 Python 和素材浏览采用桌面原生文件选择窗口。浏览器运行时使用系统 PowerShell 的绝对路径，避免 PATH 缺失导致的 `WinError 2`。
- STTN 视频写入检查 FFmpeg 启动、帧尺寸、编码退出码与错误输出；合成音轨后验证结果，完整解码通过才登记为已完成。保留原片及已有离线引擎文件。
- 任务失败显示处理阶段、视频名称、实际原因和处理建议；技术详情保留工具、退出码和原始错误。日志默认优先展示错误与提醒，可筛选任务并导出详情。
- AI 去字幕页面右上角提供本页面的设置入口，左侧依次为完整制作设置、本地 AI 引擎、云端服务连接；切换和保存设置保持当前预览与弹窗状态。
- 移除预处理和 AI 去字幕页面的“本次制作接口”卡片，保留现有接口管理和任务调用规则。

## 安装与兼容

客户安装文件放在 `release/v0.9.1/对外发送/`。旧客户先退出软件，再覆盖安装到原目录；已有有效设备授权、用户素材和已导入的 v1 离线 AI 引擎继续保留。主安装包不包含模型，新装本地 AI 仍需独立 v1 引擎包。

应用发行清单签名与授权校验保持启用。安装程序包含 VC++ 与 WebView2 环境检查；无需更改系统 PATH 来打开文件选择窗口。

## 验证范围

构建输入记录和验收摘要保存在 `versions/v0.9.1/`，详细本机证据保存在 `release/v0.9.1/验收证据/`。验收摘要只记录本轮实际完成的检查。

本轮已完成 10 组编译版检查共 384 项、使用编译后端的 Edge 界面检查 40 项；其中 STTN 真实视频检查 13 项。最终 1046 个文件纳入应用完整性签名，90 项构建输入记录 SHA256。最终安装包已实际隔离安装并验签，旧永久授权可启动桌面程序；临时安装已清理，原授权、快捷方式和安装记录已恢复。

按用户要求停止后续测试，未完成本轮安装版文件选择器的人工点击确认。编译版选择器契约和空 PATH 系统工具定位检查已完成。

客户截图对应电脑的最终根因仍需其实际日志确认；本版针对已复现的故障处理链修复并验证。短样片通过不等于所有显卡、全新 Windows 环境或所有客户素材都已实测。
