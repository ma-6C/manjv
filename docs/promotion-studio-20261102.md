# 智能推广挂载替换记录（2026-11-02）

本次替换工作区内的“推广挂载”页面与任务链路。目标是将高光选段、多段混剪和各平台挂载任务关联起来。旧人工截取、推广包、收益台账和历史记录继续可用。

## 实现范围

1. 选择本剧的源视频（最多500集），读取同名 UTF-8 SRT；没有 SRT 时调用已有独立 Whisper 运行环境。文字模型复用“文案与封面”的连接路由，不另存密钥。
2. 按台词时间码分析冲突、反转与悬念。长转写分块筛选高光后跨集规划，覆盖所选全部转写；不静默截断末尾。当前为台词分析，没有实现画面语义高光识别。
3. 校验模型 JSON、素材索引、有限时间、时长和重叠。AI 未返回有效方案时停止，不以随机片段代替高光。
4. 真实 FFmpeg 多段切割和拼接，统一720×1280、30fps、立体声音轨、响度和结尾引导文字。输出写入“智能推广”，不覆盖原片或整剧成品。
5. 红果社区、抖音、视频号分别保存账号、剧名和入口；分别生成不可变任务快照。成片与目标配置相同的任务不重复创建。
6. 支持先分析再预览、按方案混剪、一次完成分析和混剪；可选择混剪后直接进入平台任务执行。默认上传草稿，正式发布方式需要在三平台配置中选择。

## 平台实现和实际边界

| 平台 | 当前实现 | 尚需验证或补齐 |
|---|---|---|
| 红果社区 | 独立推广任务、成片与文案、挂载清单、手机发布包、实际跳转核对 | 没有已验证的社区桌面投稿API；没有实现手机自动发布，不走整剧投稿后台 |
| 抖音 | 独立浏览器会话、上传、添加小程序分享链接、回显检测、草稿或正式提交适配 | 真实账号的挂载权限、当前页面选择器、实际投稿和点击跳转均未实测；不宣称支持任意红果推广卡或APP拉新锚点 |
| 视频号 | 内置浏览器挂小程序短剧/原生剧集；也可调用外部 MatrixMedia CLI | 真实账号当前页面、权限和发布结果尚未实测；外部 MatrixMedia 未自动安装或随本软件捆绑 |

内置浏览器只访问固定的官方抖音和视频号上传入口。用户本人在可见窗口完成扫码/安全验证。未确认挂载回显不执行正式发布。会话文件仅写入本机独立目录，不展示到前端。结果未知时不自动重试。

发布回执区分 `prepared`、`queued`、`running`、`needs_phone`、`draft_saved`、`published_unverified`、`login_required` 和 `needs_attention`。最后一个阶段“点击跳转已核对”仍要求本人查看实际作品、填写作品ID或链接与说明。草稿、提交按钮、引导字幕、打开后台均不视为实际挂载成功。

中断的远端任务恢复为需要核对；只有本人确认未发布才能重新准备。已经保存的草稿不自动重复上传。可在三平台配置中改为正式发布后，针对同一成片建立新的目标任务。

## 与检索项目的结合

- 高光与剪辑复用当前软件已有的 ASR、模型路由和 FFmpeg，避免再打包一套重复运行环境；没有整包引入 NarratoAI 或 DramaClip，也不声称已经验证它们的实片效果。
- 视频号提供 [MatrixMedia](https://github.com/hanliang97/MatrixMedia) 的外部 CLI 适配，传入 `--sph-drama-id` 或 `--sph-series-id`，实际值为完整剧名。MatrixMedia 账号分组名应与本软件账号备注一致。没有复制其 GPL 源码到本项目。
- 内置挂载适配是本项目自己的浏览器流程。行为参考平台入口及 [挂载说明](https://github.com/hanliang97/MatrixMedia/blob/main/docs/sph-links.md)，不能把本地模拟页面测试视为真实平台验收。
- [抖音自主挂载文档](https://developer.open-douyin.com/docs/resource/zh-CN/mini-app/open-capacity/flow-entrance/douyin/video/self-mount/)说明小程序分享链接和账号权限要求。

## 验证与启动

- `verify_promotion_studio.py`：隔离 HTTP/API 和真实 FFmpeg 测试；使用同名真实 SRT、模拟模型结果及模拟远端回执。逐帧核对红色第一集与蓝色第二集的混剪顺序，检查时长、音轨和末帧解码。
- `verify_promotion_studio_ui.cjs`：隔离浏览器检查配置保存、重新加载、分析预览、多段混剪、三平台任务和1440/1024/390宽度。
- `verify_promotion_publish.py`：本地 HTML 模拟页面验证两个视频号类型、隐藏重复行、抖音入口回显和挂载失败不发布。
- `verify_promotions.py`：旧人工钩子/推广包/收益流程回归。
- 这些检查不登录真实账号，不消耗真实文字模型额度，不执行平台发布，也不证明高光质量或真实推广转化率。

工作区启动器 `漫剧工坊.exe` 对应 `Launcher.cs`，启动本目录 `desktop.py`。关闭旧窗口后从本工作区启动即可加载源码版新页面。此前发布的独立安装包没有被覆盖。`build_hardened.py` 已加入两个新模块，后续发行仍需独立重建并签名验收。
