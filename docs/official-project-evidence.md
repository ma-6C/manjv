# 剪映真实工程与官方窗口截图

开发源码已取消自绘时间线工程图。当前入口为「剪映工程与截图」，不是旧的轨道布局图片生成器。本次未打包。

## 实际使用

1. 在左侧自由选择视频及顺序，最多30个。可选择原片、当前成片或去字幕结果作为工程输入。
2. 生成可编辑剪映草稿。草稿包含实际视频、提取的原声，以及同名 SRT 字幕（如果存在）。按镜头分段时采用真实素材区间。
3. 点击「导入剪映草稿库」。软件复制到新的独立目录，重定位素材路径，不覆盖既有草稿，不重写剪映总索引。
4. 打开剪映，在草稿列表选择刚导入的工程。核对画面、时间线及原声音轨，再根据实际需要继续编辑。
5. 点击「选择官方窗口并截图」，选择正在编辑的窗口，确认本剧工程已打开、时间线与预览可见，在30秒内切换到该剪映窗口。
6. 软件直接采集该前台窗口的原始 PNG，登记窗口进程、官方数字签名、时间、图片 SHA256 和剧目关联。截图不拼接、不绘制、不添加轨道。
7. 回到发布工作区重新检查。只有登记且哈希匹配的真实官方窗口截图，才计入工程证明图片。

本机检测到剪映专业版 `11.6.0.14552`，主程序位于 `D:\剪映\JianyingPro\JianyingPro.exe`，当前草稿位置为 `D:\剪映\JianyingPro Drafts`。其他电脑可自动检测或选择实际安装和草稿路径。

草稿通过第三方 `pyJianYingDraft` 格式桥接建立，不是剪映官方 SDK。官方火山文档也介绍了将导出的剪映工程目录放入剪映草稿位置，再在客户端打开的方式；工程能否使用仍以实际剪映版本打开结果为准。[官方控制台剪辑文档](https://docs.volcengine.com/docs/video_on_demand/ClippingthroughConsole?lang=zh)

## 状态与范围

- **草稿已生成**：文件和媒体校验完成，尚未证明编辑器已打开。
- **已导入草稿库**：独立副本已写入，不等于剪映已经接受或读取。
- **打开剪映**：启动已核验的官方程序。用户需要在列表打开相应工程，不将启动进程冒称打开指定工程。
- **官方窗口来源已核验**：截图来自有效官方签名程序的实际编辑窗口，同时检测到时间线和导出控件。不是首页、启动画面或独立播放器。
- **工程归属由本人确认**：截图内容与当前剧目的对应关系由操作者核对，不由窗口标题猜测。
- **平台认可**：需以实际平台审核为准。本工具没有提交此验收截图。

连续制作窗口会先尝试通过当前版本提供的唯一原生草稿控件打开对应工程。未核验打开结果时，保留在“交接到剪映”，分别显示工程生成、复制导入和实际打开状态。草稿列表使用实际导入后的完整名称（包含独立导入后缀），以便与剪映列表对应。

手动打开工程后可点“重新检测并继续”。此次检测复用原操作和已导入副本；轮询不会重复点击剪映，也不重跑编码、生成草稿或复制文件。只有实际观察到对应工程标题及真实时间线，才能继续到截图或后续资料步骤。窗口识别能力仍受剪映版本影响。

剪映会改写导入副本的草稿与元数据。已登记的编辑器副本允许正常原生改写，素材路径和原登记素材哈希继续核对；软件不会解密、解析或覆盖编辑器改写后的内容。原始生成工程仍严格校验。原有真实视频分镜帧继续单独保存，用于分镜材料；不会拼接成官方工程界面。

即梦提供官网入口和实际项目页面截图路径。即梦具有智能画布和多图层编辑；本次没有验证到可替代真实项目截图的官方工程时间线导出 API。窗口采集要求官方浏览器签名、地址栏精确来源和可识别的项目/画布路径，不会仅凭标题带“即梦”就通过。该路线尚未完成登录后实际画布验收。[即梦官网](https://jimeng.jianying.com/)

手动导入本机截图会原样保留，但标为“本人导入、来源未核验”，不能自动升级为已验证官方截图。旧自绘图片、拼接工程记录、复制改名后的图片，以及资料包中自称“officialEvidence”的字段，都不能绕过服务端来源登记。
