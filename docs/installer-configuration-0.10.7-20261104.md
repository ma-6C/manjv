# 0.10.7默认保留用户配置

安装向导“发现已安装版本”页新增“卸载旧版本时保留用户配置”，默认勾选。只有选择“安装新版本前，先卸载旧版本”后才可更改这个选项。勾选、取消和返回页面状态已在无安装行为的原生预览中核对。

## 两种行为

- 默认勾选：不读写用户配置，旧版卸载后继续沿用原设置。
- 取消勾选：在卸载前检查配置可读、备份目录可写及软件未运行；旧版成功卸载后，先备份原state.json，再只重置软件设置字段。重置完成后写入新版程序。
- 未选择卸载时不执行重置，静默方式明确传`/KEEPCONFIG=0`但没有`/REMOVEOLD=1`会拒绝执行。

配置与项目记录混合保存在state.json，辅助程序不会删除这个文件或用户数据目录。仅将config恢复为空对象（启动时由现有默认设置补全），并移除aiConnectionTests和trackSheetOptions两个设置缓存字段；其他字段、项目记录、账号备注和历史记录保留。jobs.json、授权文件、模型、引擎及小v喵程序选择/运行数据均不清理。

完整原文件按原字节备份到用户数据目录的settings-backups，替换使用同目录临时文件和原子替换。配置无效、UTF-8损坏、备份不可写或存在桌面程序的数据目录互斥体时拒绝重置。辅助程序使用MANJU_DATA指定目录，否则使用当前用户LocalAppData下的ManjuStudio，与应用的数据路径规则一致。

实现为installer_upgrade.nsh、InstallerSettings.cs和build_installer.py。复用Windows已有.NET Framework组件，没有向客户新增Python或Node运行要求。
